These original, synthesized notification chimes are bundled with iNfinity eXpress.
No third-party recordings or samples are used. Both are 650 ms, mono, 44.1 kHz,
16-bit PCM WAV files with softened attacks and decaying harmonics.

- `success.wav`: ascending E5–A5 chime.
- `error.wav`: descending A4–E4 chime.
